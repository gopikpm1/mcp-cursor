# Planets Query (Planets360)

## When to use

- Looking up today's Panchang (Tithi, Nakshatra, Yoga, Karana, Rahu Kalam) for a location
- Getting daily, weekly, or monthly horoscope by Rashi or Nakshatra
- Generating a Janam Kundli birth chart with Dasha Bhukti timeline
- Checking planet transits (Gochar) for the nine grahas
- Running Dosha checks (Mangal Dosha, Sade Sati) and remedy suggestions

## Instructions

1. Confirm the Planets360 MCP server is connected and the requested tool is available.
2. Choose the data category: panchang, horoscope, kundli, transits, dosha, or remedies.
3. Supply the required MCP input parameters (e.g., date, location/timezone, Rashi, planet name, birth details).
4. Invoke the matching Planets360 MCP tool and read the structured response.
5. Cross-reference results against known Vedic attributes (Rashi lord, Nakshatra Pada, graha significations).
6. Summarize findings clearly, citing the source (Planets360) and any relevant caveats.
7. Flag missing or ambiguous values for manual review — astrological readings are guidance, not certainty.

## Example queries

- "What is today's Panchang for Chennai?"
- "Give me the weekly horoscope for Mesha (Aries) Rashi."
- "Generate a Kundli for someone born on 15-Aug-1990 at 05:30 IST in Chennai."
- "When is Saturn's next transit (Gochar) and its Sade Sati phase?"
- "Check Mangal Dosha for this Kundli and suggest remedies."
